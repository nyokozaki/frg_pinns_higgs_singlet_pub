# frg_pinns_higgs_only

Singlet-free reduction of `frg_pinns_higgs_singlet/`: Higgs + external gauge/top
only, one field direction $\rho$. Used for the cross-check of Secs. 4.3 / 6.1
(isolating the role of the soft perturbative-consistency penalty from any
singlet-specific structure).

Configuration:
- `perturbation/config_params.py` — benchmark point and temperature (`T_RAW`)
- `hyperparams.py` — all loss weights

See the repository-root `README.md` for the workflow and figure→script map.
